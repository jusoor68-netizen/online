Offline Encrypt — urlencode(base64(openssl_encrypt(..., OPENSSL_RAW_DATA))) AES-128-CBC

This page runs fully offline, but WebCrypto requires a secure context. Use http://localhost (e.g., python -m http.server 8080) or HTTPS.

Accepts: 16-char text OR 32 hex chars. Longer will be truncated; shorter will be zero-padded.
Same rule as key. For AES-CBC the IV must be 16 bytes.
